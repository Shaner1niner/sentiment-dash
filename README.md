# SETA Sentiment Dashboard

This is the public static dashboard surface for SETA.

It contains the browser dashboard, public runtime assets, and sanitized static data payloads used for GitHub Pages.

The private data pipeline, database workflows, model operations, refresh automation, and internal QA process are maintained outside this public repository.

SETA is an informational market-emotion and narrative-structure dashboard. It is not a trade instruction system, a price target system, or financial advice.
